# TenderHub

A platform connecting buyers and sellers: buyers create RFQs, invite suppliers, compare quotes side by side and award the best bid.

Plain HTML/JavaScript Progressive Web App, with no build step. Upload the files to any static web host.

## Settings
Everything you normally change is in `config.js`: Supabase keys, plans and prices, PayPal links, dropdown lists and the terms template.

With the Supabase keys left empty, the app runs in **demo mode**. In demo mode, data is saved only in the visitor's browser, and sample accounts use the password `demo1234`.
